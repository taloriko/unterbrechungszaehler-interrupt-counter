# Interruption Counter

[Deutsch](../de/README.md) · [Schwäbisch](../swg/README.md) · [Project home](../../README.md)

The Interruption Counter records a push button or dry contact, stores each timestamp on the ESP32 and presents the data locally in a browser.

## Features

- event capture and persistent storage
- daily view, history, details and heatmaps
- CSV export
- NTP and optional DS3231 RTC
- optional SH1106 OLED
- fallback Wi-Fi access point
- standalone battery/power-bank mode
