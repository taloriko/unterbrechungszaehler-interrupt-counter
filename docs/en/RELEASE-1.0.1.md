# Version 1.0.1 – Test focus

This version contains only bug fixes and optimizations for the existing web interface.

Before merging, verify especially:

- Open the language selector once on a smartphone and switch repeatedly between languages.
- No repeated selector dialogs and no frozen browser UI.
- Ring-buffer labels remain stable without flicker.
- Values in the Device section do not cause visible page rebuilds.
- The RAM display remains calm and is visibly updated only at longer intervals.
- Heatmaps, export, display settings, RTC/NTP and counter buttons continue to work unchanged.
