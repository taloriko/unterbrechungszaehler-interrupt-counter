# Unterbrechungszähler

[English](../en/README.md) · [Schwäbisch](../swg/README.md) · [Projektstart](../../README.md)

Der Unterbrechungszähler erfasst einen Taster oder potentialfreien Kontakt, speichert den Zeitpunkt auf dem ESP32 und stellt die Daten lokal im Browser dar.

## Funktionen

- Ereigniserfassung und dauerhafte Speicherung
- Tagesansicht, Verlauf, Details und Heatmaps
- CSV-Export
- NTP und optionale DS3231-RTC
- optionales SH1106-OLED
- Fallback-WLAN
- Autarkbetrieb
