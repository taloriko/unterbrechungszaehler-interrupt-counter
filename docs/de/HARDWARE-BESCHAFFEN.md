# Hardware beschaffen

> **Status: In Arbeit**

Für den aktuell getesteten Aufbau werden benötigt:

- ESP32 Dev Module / ESP32-WROOM-32
- potentialfreier Taster, z. B. Eaton M22
- optional: potentialfreier Schiebeschalter für den Autark-Modus
- USB-Datenkabel zum Flashen
- geeignete 5-V-Stromversorgung für den normalen Betrieb
- optional für mobilen Betrieb: Akku oder USB-Powerbank

## Optional: magnetische Befestigung

Für eine einfache abnehmbare Befestigung kann das Gehäuse zusätzlich mit einem **MagSafe-/Magnetring** ausgestattet werden.

Der Ring dient dabei nur zur mechanischen Befestigung und hat keine elektrische Funktion.

Die konkrete Ausführung und Befestigung am Gehäuse ist noch **in Arbeit**.
