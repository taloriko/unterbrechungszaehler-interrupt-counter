# Unterbrechungszählerle

[Deutsch](../de/README.md) · [English](../en/README.md) · [Projektstart](../../README.md)

S Kistle zählt Unterbrechunga: Taster oder potentialfreier Kontakt auslösa, Zeitpunkt speichera und später im Browser gugga, wie oft wieder oiner was wollt hot.

## Was ka s?

- Unterbrechunga dauerhaft speichera
- Heit, Verlauf, Details und Hitzekärtla zeiga
- CSV-Dada raustraga
- Zeit über NTP oder optional über a DS3231-RTC
- optionales SH1106-OLED
- eigenes Fallback-WLAN, wenn s normale WLAN grad net will
- Autarkbetrieb mit Akku oder Powerbank
