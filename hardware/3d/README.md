# 3D-Druck / Gehäuse

> **Status: In Arbeit**

Für den Unterbrechungszähler ist ein eigenes 3D-gedrucktes Gehäuse vorgesehen.

## Gehäusefunktionen

- Aufnahme für den ESP32
- Öffnung für den Taster
- Öffnung für den optionalen Schiebeschalter
- Kabel-/USB-Zugang
- Möglichkeit zur Aufnahme eines **MagSafe-/Magnet-Kleberings** auf der Unterseite

Der MagSafe-Ring dient ausschließlich zur mechanischen Befestigung des Geräts.
