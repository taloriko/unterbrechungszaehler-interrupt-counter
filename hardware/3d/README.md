# 3D-Druck / Gehäuse

Das vorgesehene Gehäuse unterstützt:

- Aufnahme für den ESP32
- Öffnung für den Taster
- Öffnung für den optionalen Schiebeschalter
- Kabel-/USB-Zugang
- Aufnahme eines MagSafe-/Magnet-Kleberings auf der Unterseite

Der MagSafe-Ring dient ausschließlich zur mechanischen Befestigung des Geräts.

## Druckdateien

Im Repository ist derzeit keine druckfertige STL-/3MF-Datei enthalten.
